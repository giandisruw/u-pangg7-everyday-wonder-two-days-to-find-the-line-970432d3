[![make.fun](https://make.fun/badge/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3.svg)](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

One sentence, up to 200 characters, on a small moment of wonder in everyday life.

## Entry

> My shadow on the wet pavement walked a half-step ahead, impatient to get home before me.

`main.py` writes that single sentence deterministically to `/output/entry.txt` — no network, no randomness, no input files. It asserts the sentence is 1–200 characters and a single sentence before writing, so the gate can never receive an invalid file from this program.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
